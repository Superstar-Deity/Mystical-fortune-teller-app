# 🔮 Mystical Fortune Teller App

A mystical zodiac fortune teller built with **HTML, CSS, and JavaScript**.

Enter your name and zodiac sign to reveal your cosmic luck score, status, and a three-card fortune reading. You can also search through the fortune archive and sort the fortunes alphabetically.

## ✨ Features

- Enter your name and zodiac sign
- Generate a random Cosmic Luck Score from 1–100
- Receive a **Blessed** or **Cursed** status
- Generate three unique fortune cards
- Save readings during the current session
- Search the fortune archive using keywords
- Sort fortunes alphabetically
- Responsive design for smaller screens
- Mystical purple and gold visual theme
